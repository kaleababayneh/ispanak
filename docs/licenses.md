Otomatik üretildi: `uv run pip-licenses --format=markdown --order=license`

Tüm üçüncü taraf bağımlılıklar açık kaynak lisanslıdır: ağırlıkla MIT / BSD /
Apache-2.0, artı üç MPL-2.0 (`certifi`, `bidict`, `tqdm`; dosya düzeyinde
zayıf copyleft, kullanımı kısıtlamaz) ve üç PSF (`typing_extensions`,
`aiohappyeyeballs`, `distlib`). GPL, AGPL, SSPL veya ticari kısıtlı paket
yoktur. `chainlit` ve `plotly` 23 Eylül'de eklendi (Apache-2.0 / MIT); büyük
bağımlılık ağacı `chainlit`'in. `lakehouse-agent` projenin kendisidir (MIT).
